# PeerLearn

PeerLearn is a collaborative, peer-based learning resource recommendation platform designed to help students discover, request, and share academic materials such as lecture notes, presentations, videos, and study guides.

## Project Vision
To build a collaborative learning ecosystem where students seamlessly discover and share high-quality academic materials to enhance mutual learning and academic productivity.

## Key Objectives
- Provide a centralized hub for students to post topic-specific resource queries and receive prompt peer recommendations.
- Integrate a peer-review and upvoting system to ensure the credibility and relevance of shared resources.
- Categorize and tag educational content across subjects and courses for streamlined discovery.

## Key Functional Modules
1. **User Authentication & Profile Management:** Registration, role handling, and contribution tracking.
2. **Resource Request & Recommendation Engine:** Submitting topic queries and sharing recommended materials.
3. **Content Repository:** Managing attachments (PDFs, PPTs, notes) and reference video links.
4. **Rating & Search System:** Tag filtering, keyword search, and peer upvoting/downvoting.

## Agile Workflow
- **Project Management Tool:** Taiga
- **Version Control:** Git / GitHub
